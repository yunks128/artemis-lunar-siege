# ARTEMIS: LUNAR SIEGE

**▶ Play: https://yunks128.github.io/artemis-lunar-siege/**

A single-file browser roguelike survival game. You are the last EVA crew at Shackleton Base on the lunar south pole. Something under the regolith woke up. Hold the base relay for **15 minutes** until the Artemis IV lander can divert, then kill what comes for it.

No build step, no dependencies, no assets — one `index.html`, about 70 KB. Everything (art, audio, physics) is generated at runtime with Canvas 2D and the Web Audio API.

---

## Play

| | |
|---|---|
| **Move** | `W A S D` / arrow keys, or drag anywhere on touch |
| **Attack** | Automatic — your only job is positioning |
| **Draft** | `1` `2` `3` to pick an upgrade card |
| **Pause** | `Esc` or `P` |
| **Language** | EN / 한국어 toggle, top right |

## Rules

- Aliens that reach the base chew through **Base Integrity**. Enemies circled in red are ignoring you and heading for the base — cut them off.
- If base integrity hits zero, or your suit fails, the run ends.
- Blue shards are XP; they pull in from within your magnet radius. Every level offers three modules.
- **The Harvester** surfaces at 10:00. **The Crater Monarch** arrives at 15:00 and has three phases. Kill it to win.

## Systems

Five weapons, eight passives, five legendary evolutions.

| Weapon | Behavior | Legendary (max weapon + paired passive ≥ 3) |
|---|---|---|
| ➤ Pulse Rifle | Auto-targets nearest hostile | **Railgun** — full pierce, massive damage |
| ◍ Escort Drones | Orbiting bodies, contact damage | **Aegis Ring** — larger, burning |
| ◉ Regolith Mines | Proximity charges dropped in your wake | **Seismic Charge** — chain detonations |
| ☀ Solar Lance | Piercing beam through a whole column | **Solar Array** — four rotating lances |
| ◎ EMP Nova | Shockwave that damages and shoves | **Singularity** — inverts, pulls enemies in |

Passives: Servo Boots, Reactor Core, Magnet Coil, Cryo Coolant, Amplifier, Ablative Plating, Focus Optics, Nano-Weave.

Two or three weapons leveled deep beat five weapons at level 2.

## Run it locally

```bash
git clone https://github.com/yunks128/artemis-lunar-siege.git
cd artemis-lunar-siege
python3 -m http.server 8000   # or just open index.html directly
```

## Deploy

GitHub Pages serves `index.html` from the repository root on the `main` branch. `.nojekyll` is present so nothing is filtered.

## Development

`index.html` is generated by concatenating the sources in `src/` into the `<script>` block:

```bash
node --check /tmp/all.js   # syntax
node test.mjs              # headless Playwright smoke test: bosses, level-ups,
                           # legendary evolutions, win/lose states, FPS, mobile
```

The bundled test drives a full run and asserts no console errors. Last measured: 60 fps with 300 simultaneous enemies at 1280×800.
